    Step 3

    Agree the scope

    These are the decisions the system will not make on your behalf, because each one has a business consequence. Your answers become a contract that every later stage reads and the final report is judged against.

    Excluded URLs are routed, never dropped. Anything you leave out emits a 410 Gone or a redirect, so search engines drop it cleanly instead of finding a dead page.

    Step 4

    Review content and templates

    Every page has a recommended template and a match score. Change any of them — the leftover count updates immediately, so you can see what a swap would cost before committing to it.

    Build and verify

    Generates the Next.js project, re-hosts every image, then checks the result mechanically. The checks read the built output — they are not assertions in a README.

    Step 6

    Responsive preview

    Original and migrated, side by side, at the three breakpoints the component library is built against. This doubles as the responsive check.

    The original loads from the live WordPress site, so some pages may refuse to render in a frame — that is the source site's security policy, not a migration failure. The migrated column is served locally from the static export.
